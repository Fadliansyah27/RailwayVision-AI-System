# RailwayVision AI — Complete Documentation Package

This package contains the baseline project documents and additional implementation specifications.

## Start here
1. Read `README.md`.
2. Read `DECISIONS_AND_OPEN_QUESTIONS.md` and identify items that require stakeholder confirmation.
3. Read all requirements, architecture, data, API, AI governance, security, QA, and deployment documents.
4. Give `MASTER_PROMPT.md` and the entire folder to your coding agent.
5. Ask the agent to execute Stage 0 only, review its audit and plan, then proceed stage by stage.

## Important
This is a proposed enterprise prototype baseline, not KCIC-approved operational documentation. Use synthetic/demo data until KCIC authorizes real data, locations, workflows, infrastructure access, and deployment. AI is advisory and requires qualified human review. No train-control or signalling integration is in scope.
